# 🎬 Anime Viral Edits (Chainsaw Man Style)

Automated anime edit creator using GitHub Actions.

## Features
- Downloads anime episodes from Google Drive
- Creates 60fps smooth edits in Chainsaw Man style
- 1080x1080 square format (Instagram/YouTube Shorts)
- Fast-paced cuts with boosted saturation
- Auto-uploads to YouTube

## Setup
1. Add secrets to GitHub repo:
   - `CLIENT_ID` - YouTube OAuth client ID
   - `CLIENT_SECRET` - YouTube OAuth client secret
   - `REFRESH_TOKEN` - YouTube OAuth refresh token

2. Run workflow manually or wait for daily schedule (12pm)

## Style
- 60fps interpolation
- High saturation and contrast
- Speed ramping (1.2x faster)
- Square 1080x1080 format
- 8-12 fast clips per 60-second edit
